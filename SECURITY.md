# Security

Quill runs on your PC and keeps your voice there. We take that seriously.

## Reporting a vulnerability

Please don't open a public issue. Instead, report it privately through GitHub's [private vulnerability reporting](../../security/advisories/new).

Include what you found, how to reproduce it, and the Quill version. We'll reply as soon as we can and keep you updated until it's fixed.

## Supported versions

Only the [latest release](../../releases/latest) receives security fixes. Quill updates itself, so staying current is easy.
